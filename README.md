# OncoVigil

Interactive cancer development pipeline — mRNA individualized vaccines, T-cell engagers, IL-15 Bioshield, CAR-T — with step-by-step mechanism illustrations, company IR/trial contacts, and a **Refresh pipeline** button that pulls new recruiting studies from [ClinicalTrials.gov](https://clinicaltrials.gov).

**Live:** [alecmazo.github.io/OncoVigil](https://alecmazo.github.io/OncoVigil/)  
**Hub:** [alecmazo.github.io/application-hub](https://alecmazo.github.io/application-hub/)

## Weekly refresh

Oncology moves about one meaningful readout per week. Hit **Refresh pipeline** on the board. New NCT records (mRNA, T-cell engagers, CAR-T, IL-15, ADCs — prostate, colon, melanoma and related) land as cards with a mechanism sketch, sponsor, and ClinicalTrials.gov link. Results persist in the browser.

## Stack

TanStack Start + React in preview; static SPA on GitHub Pages (`npm run build:spa`).
